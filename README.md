# 🐍 Automate the Boring Stuff with Python — Automation Portfolio

Welcome to my Python automation repository! This project documents my hands-on journey working through Al Sweigart's *"Automate the Boring Stuff with Python"*. 

Here, you'll find practical scripts and mini-applications I've built to eliminate repetitive tasks, manipulate files, scrape the web, and automate everyday workflows.

---

## 🛠️ Skills & Libraries Demonstrated

* **Core Python:** Functions, data structures (lists, dictionaries), string manipulation, and error handling (`try`/`except`).
* **Pattern Matching:** Regular Expressions (`re`) for parsing and validating text data.
* **File Management:** Reading, writing, and organizing files/directories using `os`, `shutil`, and `pathlib`.
* **Web Scraping & APIs:** Extracting web data and interacting with web pages using `requests`, `BeautifulSoup4` (`bs4`), and `selenium`.
* **Document & Data Automation:** Automating spreadsheets, PDFs, and Word documents with `openpyxl`, `PyPDF2`, and `python-docx`.
* **GUI & Task Scheduling:** Simulating mouse/keyboard actions with `pyautogui` and scheduling tasks.

## 🚀 Getting Started

To run these scripts locally on your machine:

### 1. Clone the repository
```bash
git clone https://github.com/haojiegit/Python_Learning.git
cd ./Python_Learning
```

### 2. Set up a virtual environment (Recommended)
```bash
python -m venv venv
# On Windows:
venv\Scripts\activate
# On macOS/Linux:
source venv/bin/activate
```

### 3. Install dependencies (Coming up)
```bash
pip install -r requirements.txt
```

### 4. Run a script
```bash
python src/script_name.py
```
